Semana 12 - WordCount con Hadoop MapReduce

Guía práctica para ejecutar WordCount con Hadoop y Docker usando el archivo comentarios.txt, cargándolo a HDFS, procesándolo con MapReduce y validando el resultado desde YARN.

Semana 12 Tema principal: WordCount Hadoop + Docker + HDFS MapReduce + YARN
Objetivo Paso a paso Resultado YARN Cierre Desafío grupal

Objetivo

Procesar un archivo de texto en Hadoop para contar cuántas veces aparece cada palabra.

Flujo de la práctica: comentarios.txt → HDFS → MapReduce WordCount → resultado → YARN.

Ingestión

Primero se crea el archivo y se sube a HDFS.

Procesamiento

Luego Hadoop ejecuta WordCount con MapReduce.

Validación

Al final se consulta la salida en HDFS.

Monitoreo

La ejecución se revisa en YARN desde el navegador.

Idea de sesión: aunque el archivo es pequeño, el flujo replica el mismo modelo que se usa en proyectos Big Data reales: ingreso de datos, procesamiento distribuido, salida y revisión operacional.

Paso a Paso de la Práctica

Sigue exactamente este orden para levantar Hadoop, cargar el texto y ejecutar WordCount.

1

Levantar Hadoop con Docker

Hazlo desde la carpeta raíz del proyecto.

Terminal de tu computadora
Comandos 
docker compose -f docker-compose.week7.yml up --build -d
docker compose -f docker-compose.week7.yml ps
Debes verificar: que los servicios del clúster estén activos antes de continuar.
2

Entrar al contenedor namenode

Desde aquí trabajarás con HDFS y el archivo de texto.

Terminal de tu computadora
Comando 
docker exec -it namenode bash
3

Crear el archivo comentarios.txt

Usa exactamente este contenido dentro del contenedor.

Dentro del contenedor namenode
Texto y verificación 
cat > comentarios.txt << 'EOF'
java dificil
java interesante
hadoop dificil
docker util
big data interesante
java util
hadoop docker
datos datos datos
EOF

cat comentarios.txt
Debes ver: las 8 líneas del archivo impresas en pantalla.
4

Crear la carpeta de entrada en HDFS

Aquí defines la ruta donde Hadoop leerá el archivo.

Dentro del contenedor namenode
HDFS 
hdfs dfs -mkdir -p /user/root/input
5

Subir el archivo a HDFS

Después verifica tanto la ruta como el contenido.

Dentro del contenedor namenode
HDFS 
hdfs dfs -put -f comentarios.txt /user/root/input/
hdfs dfs -ls /user/root/input
hdfs dfs -cat /user/root/input/comentarios.txt
Debes confirmar: que comentarios.txt ya vive dentro de HDFS.
6

Eliminar la salida anterior si existe

WordCount no sobrescribe carpetas de salida existentes.

Dentro del contenedor namenode
Limpieza 
hdfs dfs -rm -r -f /user/root/output
7

Ejecutar WordCount con MapReduce

Prueba primero la ruta genérica y usa la segunda si tu imagen lo requiere.

Dentro del contenedor namenode
MapReduce 
hadoop jar /opt/hadoop/share/hadoop/mapreduce/hadoop-mapreduce-examples-*.jar wordcount /user/root/input /user/root/output

hadoop jar /opt/hadoop-3.2.1/share/hadoop/mapreduce/hadoop-mapreduce-examples-3.2.1.jar wordcount /user/root/input /user/root/output
Idea clave: WordCount es el ejemplo clásico para entender cómo MapReduce separa, agrupa y cuenta datos por lotes.
8

Ver el resultado generado

La salida final queda en la carpeta /user/root/output de HDFS.

Dentro del contenedor namenode
Resultado 
hdfs dfs -cat /user/root/output/part-r-00000
9

Revisar la ejecución en YARN

Abre el panel desde el navegador para validar el job.

Navegador
URL 
http://localhost:8088
Explicación para alumnos: YARN permite revisar si el proceso se ejecutó correctamente, cuánto demoró y en qué estado terminó.

Resultado Esperado

Si el flujo salió bien, este debe ser el contenido del archivo de salida principal.

Salida esperada 
big	1
data	1
datos	3
dificil	2
docker	2
hadoop	2
interesante	2
java	3
util	2
Lectura rápida: las palabras que más se repiten son datos y java, por eso aparecen con los conteos más altos.

Qué se Aprende con WordCount y YARN

Esta práctica no solo cuenta palabras. También enseña el flujo completo de ejecución distribuida dentro de Hadoop.

WordCount

Muestra cómo Hadoop divide datos, los procesa en paralelo y consolida el resultado final.

HDFS

Permite guardar datos de forma distribuida para que los jobs puedan leerlos desde el clúster.

MapReduce

Ejecuta procesamiento por lotes, ideal para grandes volúmenes de información histórica.

YARN

Administra recursos, estados de ejecución y revisión de logs de las aplicaciones del ecosistema Hadoop.

Importancia en proyectos reales: Hadoop sigue siendo relevante cuando una organización necesita almacenar y procesar grandes volúmenes de datos con tolerancia a fallos, ejecución distribuida y trazabilidad operacional.

Desafío Grupal

Para una versión más presentable en clase, el reto es repetir la práctica usando el archivo comentarios_1000.txt en lugar del archivo pequeño de 8 líneas.

Meta del desafío: ejecutar el mismo flujo de WordCount pero con un archivo más grande para observar mejor el uso de HDFS, MapReduce y YARN.
1

Copiar el archivo al contenedor

Hazlo desde la carpeta donde tengas comentarios_1000.txt.

Terminal de tu computadora
Copia al contenedor 
docker cp comentarios_1000.txt namenode:/comentarios_1000.txt
2

Entrar al contenedor namenode

Desde aquí validarás el archivo antes de subirlo a HDFS.

Terminal de tu computadora
Acceso 
docker exec -it namenode bash
3

Verificar que el archivo existe

Basta con revisar las primeras líneas.

Dentro del contenedor namenode
Validación 
cat /comentarios_1000.txt | head
4

Subir el archivo grande a HDFS

Reutiliza la misma ruta de entrada usada en la práctica base.

Dentro del contenedor namenode
HDFS 
hdfs dfs -mkdir -p /user/root/input
hdfs dfs -put -f /comentarios_1000.txt /user/root/input/
hdfs dfs -ls /user/root/input
5

Ejecutar WordCount sobre comentarios_1000.txt

Limpia la salida anterior y vuelve a correr el job.

Dentro del contenedor namenode
MapReduce 
hdfs dfs -rm -r -f /user/root/output
hadoop jar /opt/hadoop-3.2.1/share/hadoop/mapreduce/hadoop-mapreduce-examples-3.2.1.jar wordcount /user/root/input /user/root/output
6

Revisar el resultado final

La salida seguirá apareciendo en el archivo principal del job.

Dentro del contenedor namenode
Resultado 
hdfs dfs -cat /user/root/output/part-r-00000
Reto para el grupo: comparen el tiempo de ejecución, la cantidad de palabras distintas y las palabras más frecuentes entre comentarios.txt y comentarios_1000.txt.
