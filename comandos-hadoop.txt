SEMANA 5 Y 6 - HADOOP CON DOCKER
ISIL - CURSO DE BIG DATA

GUIA PASO A PASO (VERSION OFICIAL):
https://gxjohan.github.io/hadoop_isil/

META: subir datos_200mb.csv a HDFS y verlo en http://localhost:9870, carpeta /data

ANTES DE EMPEZAR

- Windows: usa la terminal de Ubuntu (WSL) para todo.
- Mac: usa la app Terminal o la terminal de VS Code.
- Docker Desktop debe estar abierto.
- datos_200mb.csv NO viene en el repositorio. Descargalo de
  https://examplefile.com/code/csv/200-mb-csv
  ponlo en la carpeta hadoop_isil y renombralo a datos_200mb.csv

COMO SABER DONDE ESTOY (mira el inicio de la linea)

- Terminal de tu PC:            alumno@pc:~/hadoop_isil$   -> comandos git, cd, ls, docker
- Dentro del contenedor:        root@a1b2c3d4e5f6:/#       -> comandos hdfs dfs
- Navegador:                    solo miras el resultado


=============== TERMINAL DE TU PC ===============

PASO 1 - Verificar Docker

docker --version
docker compose version
docker ps

PASO 2 - Clonar el repositorio del curso y abrirlo en VS Code

cd ~
git clone https://github.com/GxJohan/hadoop_isil.git
cd hadoop_isil
code .

PASO 3 - Descargar el entorno Hadoop (dentro de hadoop_isil)

git clone https://github.com/big-data-europe/docker-hadoop.git
ls

PASO 4 - Comprobar que datos_200mb.csv esta en hadoop_isil (debe decir 200M)

ls -lh

PASO 5 - Levantar Hadoop (espera 1 minuto despues)

cd docker-hadoop
docker compose up -d
docker ps

PASO 6 - NAVEGADOR: abrir http://localhost:9870
         Debe decir: Overview 'namenode:9000' (active)

PASO 7 - Copiar el CSV al contenedor (volvemos a hadoop_isil)

cd ..
docker cp datos_200mb.csv namenode:/tmp/datos_200mb.csv
docker exec namenode ls -lh /tmp/datos_200mb.csv

PASO 8 - Entrar al contenedor namenode

docker exec -it namenode bash


=============== DENTRO DEL CONTENEDOR namenode ===============

PASO 9 - Subir el CSV a HDFS

hdfs dfsadmin -safemode wait
hdfs dfs -mkdir -p /data
hdfs dfs -put -f /tmp/datos_200mb.csv /data/
hdfs dfs -ls -h /data
exit

Debes ver: ... 200.1 M ... /data/datos_200mb.csv
(Las lineas INFO o WARN son normales.)


=============== NAVEGADOR ===============

PASO 10 - Ver el archivo

http://localhost:9870
Utilities -> Browse the file system -> /data
Debe aparecer datos_200mb.csv con 200.1 MB


=============== AL TERMINAR (TERMINAL DE TU PC) ===============

cd ~/hadoop_isil/docker-hadoop
docker compose down
